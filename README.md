# rawstonedu `.github`

Organisation-wide community defaults, applied to every repository that does not define its own:

- Pull request template and issue templates: [`.github/`](.github)
- [Contributing guide](.github/CONTRIBUTING.md) (trunk-based flow, reviews, commits)
- [Security policy](.github/SECURITY.md)
- Standard labels: [`labels.yml`](labels.yml), applied with `scripts/sync-labels.sh`

This repository is public because GitHub only serves organisation defaults from a public `.github` repository. Keep it generic: no internal names, hosts, account ids or credentials.
